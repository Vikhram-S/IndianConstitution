# Frequently Asked Questions (FAQ)

### What amendments are included?
The corpus is updated and verified up to the **Constitution (106th Amendment) Act, 2023** (Women's Reservation Bill).

### Does this package require internet access?
No. In core mode, `indianconstitution` operates 100% offline with zero external network calls.

### Is NetworkX required?
No. NetworkX is optional. Core functions like `get_article()` and `search()` run without NetworkX. Graph features like `get_graph()` require `pip install "indianconstitution[data]"`.
