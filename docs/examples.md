# Code Examples

The repository includes executable examples under `examples/`:

- [`basic_usage.py`](https://github.com/Vikhram-S/IndianConstitution/blob/main/examples/basic_usage.py): Core retrieval and search.
- [`graph_analysis.py`](https://github.com/Vikhram-S/IndianConstitution/blob/main/examples/graph_analysis.py): NetworkX graph cross-references.
- [`pandas_export.py`](https://github.com/Vikhram-S/IndianConstitution/blob/main/examples/pandas_export.py): DataFrame analytics.
- [`rag_pipeline.py`](https://github.com/Vikhram-S/IndianConstitution/blob/main/examples/rag_pipeline.py): Context building for LLMs.
- [`semantic_search.py`](https://github.com/Vikhram-S/IndianConstitution/blob/main/examples/semantic_search.py): Vector embedding search.
- [`json_export.py`](https://github.com/Vikhram-S/IndianConstitution/blob/main/examples/json_export.py): Multi-format data export.
- [`cli_demo.py`](https://github.com/Vikhram-S/IndianConstitution/blob/main/examples/cli_demo.py): Programmatic CLI usage.

Interactive Jupyter Notebooks are available in `notebooks/`:
- `notebooks/Introduction.ipynb`
- `notebooks/AI_RAG.ipynb`
- `notebooks/LegalResearch.ipynb`
- `notebooks/SemanticSearch.ipynb`
